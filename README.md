# 🌦️ Weather Analysis Dashboard

An interactive Power BI dashboard that analyzes weather data to provide insights into temperature, humidity, precipitation, wind conditions, and climate trends through interactive visualizations.

---

## 📌 Project Overview

This project showcases an interactive Power BI dashboard built to analyze weather data and present meaningful insights into various climate metrics. The dashboard enables users to explore weather patterns, compare environmental conditions, and monitor key indicators using dynamic reports and visualizations.

---

## 🎯 Objectives

- Analyze weather conditions across different locations.
- Monitor temperature trends over time.
- Compare humidity, precipitation, and wind conditions.
- Identify seasonal and climate patterns.
- Build an interactive dashboard for weather analytics.

---

## 📊 Dashboard Features

- Interactive filters and slicers
- Temperature trend analysis
- Humidity analysis
- Wind speed and direction insights
- Precipitation visualization
- KPI cards
- Interactive charts and graphs
